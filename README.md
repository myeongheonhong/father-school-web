# 아버지학교

이름표에 인쇄할 QR코드의 연결을 확인하기 위한 임시 테스트 페이지입니다.

## 현재 구성

- `index.html`: 모바일에서 읽기 쉬운 테스트 페이지
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 제공
- 별도 빌드나 서버, 외부 폰트 없이 동작
- 실제 행사 사진과 개인정보는 포함하지 않음

## 후속 작업

같은 GitHub Pages 주소를 유지하면서 Next.js 정적 내보내기 또는 별도 서비스로 연결하는 시작 페이지로 교체합니다. 운영 주소를 유지하면 인쇄한 QR코드를 다시 만들 필요가 없습니다.

페이지가 완성되면 검색 노출 정책에 맞게 HTML robots 메타 태그를 조정합니다.
